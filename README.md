Job Portal
A full-stack job portal built with the MERN stack. The application allows job seekers to browse jobs, manage their resumes, and apply for positions. Recruiters can create company accounts, publish and manage job listings, and review applicants.
Features
Job seekers
- Browse available job listings.
- Search and filter jobs by title, category, and location.
- View job descriptions and company information.
- Sign in through Clerk.
- Upload or update a PDF resume.
- Apply for jobs and view application status.
Recruiters
- Register and sign in with a company account.
- Upload a company logo.
- Post new jobs with a rich-text description.
- View and manage posted jobs.
- View applicants and their submitted resumes.
- Update application status.
- Change job listing visibility.
Tech Stack
Frontend: React 18, Vite, React Router, Tailwind CSS, Axios, Clerk React, React Toastify, Quill, Moment.js.

Backend: Node.js, Express, MongoDB, Mongoose, Clerk Express middleware, JWT (recruiter authentication), bcrypt, Cloudinary, Multer, Sentry integration.

Getting Started
Prerequisites
- Node.js (LTS recommended) and npm
- MongoDB (local instance or MongoDB Atlas)
- Clerk application credentials
- Cloudinary account and API credentials
1. Clone the repository
git clone <your-repository-url>
cd job-portal
2. Configure and run the backend
cd server
npm install
Create server/.env:
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_long_random_jwt_secret
CLERK_WEBHOOK_SECRET=your_clerk_webhook_signing_secret
CLOUDINARY_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_SECRET_KEY=your_cloudinary_api_secret
Fill in the values from your own services. Do not commit this file or share its secrets publicly.

Start the backend:
npm run server
The backend uses port 5000 by default, or the value configured in PORT.
3. Configure and run the frontend
Open a second terminal:
cd client
npm install
Create client/.env:
VITE_BACKEND_URL=http://localhost:5000
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
Set VITE_BACKEND_URL to your backend URL and use the publishable key from your Clerk application.

Start the frontend:
npm run dev
Vite prints the local development URL in the terminal (usually http://localhost:5173).

GET	/api/users/applications	Get user's applications
POST	/api/users/update-resume	Upload/update user's resume


User endpoints use Clerk authentication. Company/recruiter endpoints use the recruiter token generated by the backend.
Implementation Notes
- Resume uploads use multipart form data with the field name resume.
- Company logo uploads use the multipart field name image.
- Uploaded files are stored through Cloudinary.
- Job descriptions are created with Quill's rich-text editor.
- MongoDB references connect jobs to companies and applications to jobs and companies.
Security
- Keep backend environment variables private.
- Never expose CLOUDINARY_SECRET_KEY, JWT_SECRET, CLERK_WEBHOOK_SECRET, or database credentials in frontend code.
- Only the Clerk publishable key belongs in the frontend environment.
- Configure production CORS, HTTPS, authentication checks, and deployment secrets for your hosting environment.
